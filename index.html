Desarrollo Web

HTML,CSS Y JavaScript:

Son los tres pilares damentales del desarroll que trabajan juntos para crear la pagina web dinámicas nteractivas.
HTML se encarga de la estructura y el contenido, CSS del diseño y sentacion, y JavaScript de la interactividad y funcionalidad.

Definiciones

HTML(Hypertext Markupn Language):

Es el lenguaje de arcado que define la estructura y el contenido de una pagina web. Utiliza tiquetas para delimitar diferentes elementos como párrafos, encabezados, enlaces, etc.

CSS(Cascading Style sheets):

Es un lenguaje de estilos que se utiliza para controlar la presentación de una página web.
Permite definir aspectos como los colores, fuentes, tamaños, margenes, etc, de los

JavaScript ( Program.Language):

Es un lenguaje de programación que permite agregar funcionalidad a una página web. Permite manipularelementos HTML.
Responder a eventos del usuario realizar calculos,etc.

Analogia de la web y una casa

HTML

Estructura de la casa.

Es como los cimientos las paredes, techos y distribucion de las habitaciones.

HTML define la estrctura básica de una pagina web: que elementos hay (titulo, párrafos, botones, imagenes, etc.) pero sin preocuparse en como se ven

CSS

Decoración y estilo de la casa.

Es la pinturas de las paredes, el tipo de piso, los muebles, las cortinas, el diseño de la cocina.

CSS se encarga de como se ve la pagina: colores, fuentes, alineaciones, estilos responsivos ......lo visual.

JavaScript

Los sistemas electricos y electronicos de la casa.

Es como los interruptores que encienden luces, las cuentas automaticas, el termostato inteligente.

JavaScript añade funcionalidad e interctividad haciendo que pasen cosas como respuesta a un evento.
